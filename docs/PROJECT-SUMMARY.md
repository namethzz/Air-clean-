# AirClean — สรุปแนวคิดและการทำงานของโปรเจกต์

## 1. แนวคิดหลัก

AirClean เป็นแพลตฟอร์มช่วยให้ลูกค้าหาช่างล้างแอร์จากพื้นที่ใกล้เคียง โดยใช้รูปแบบ **ตลาดงานใกล้ตัว (Marketplace) แบบ B** ลูกค้าไม่จำเป็นต้องตัดสินใจเลือกช่างตั้งแต่เริ่ม แต่ส่งคำขอพร้อมรายละเอียดงานก่อน จากนั้นช่างที่อยู่ในระยะค้นหาสามารถส่งความสนใจและเสนอราคา ลูกค้าเปรียบเทียบโปรไฟล์และราคา แล้วกดยืนยันช่างที่ต้องการด้วยตนเอง

หลักการออกแบบคือให้การจองของลูกค้าสั้นและเข้าใจง่าย ขณะเดียวกันช่างควรรู้รายละเอียดสำคัญก่อนสนใจงาน เช่น ระยะทางโดยประมาณ ประเภทที่พัก จำนวนเครื่อง วันนัดหมาย และราคาประเมิน

## 2. ขั้นตอนของลูกค้า (Customer)

1. เปิดคำขอใช้บริการ โดยเลือกตำแหน่งจากแผนที่หรือใช้ GPS แล้วกรอก/แก้ไขที่อยู่ บ้านเลขที่ อาคาร ชั้น ห้อง และจุดสังเกตได้
2. ระบุบริการ จำนวนเครื่อง รายละเอียดแอร์ วันที่และเวลาที่สะดวก
3. ส่งคำขอให้ช่างใกล้เคียง โดยไม่ต้องเลือกช่างล่วงหน้า
4. รอช่างส่งความสนใจ เมื่อมีข้อเสนอจะเห็นคะแนนรีวิว ประสบการณ์ พื้นที่ให้บริการ และราคาที่เสนอ
5. เปรียบเทียบข้อเสนอและกดยืนยันช่างหนึ่งคน เมื่อยืนยันแล้วงานจึงผูกกับช่างคนนั้น
6. ดูสถานะงาน เปิดแผนที่/Google Maps และติดตามตำแหน่งช่างเมื่อช่างเริ่มเดินทางและแชร์ GPS
7. หลังบริการ ตรวจรายงานและยืนยันการชำระเงินหน้างานตามฟังก์ชันที่ระบบรองรับ
8. เมื่องานเสร็จสิ้น ให้คะแนนช่าง 1–5 ดาวพร้อมความเห็นได้หนึ่งครั้งต่องาน คะแนนเฉลี่ยและจำนวนรีวิวของช่างจะอัปเดตทันที และแสดงในข้อเสนอของงานถัดไป

คำขอยังสามารถยกเลิกได้ในช่วงเปิดรับช่างหรือรอเลือกช่าง ตามกฎที่กำหนดใน API

## 3. ขั้นตอนของช่าง (Technician)

1. เปิดเมนู **งานใกล้ฉัน** และอนุญาตให้เว็บไซต์เข้าถึง GPS
2. เลือกระยะค้นหาที่ต้องการได้ เช่น 5, 10, 25, 50 หรือ 100 กิโลเมตร
3. ดูงานที่เรียงจากใกล้ไปไกล พร้อมประเภทที่พัก จำนวนเครื่อง รายละเอียดบริการ วันและเวลา และราคาประเมิน
4. กดสนใจรับงานเพื่อส่งข้อเสนอพร้อมราคาที่คำนวณจากราคาพื้นฐานของช่างและรายละเอียดงาน
5. รอลูกค้าตรวจสอบโปรไฟล์และยืนยันช่าง การกดสนใจยังไม่เท่ากับได้รับมอบหมายงาน
6. เมื่อได้รับการยืนยัน งานจะปรากฏในรายการงานของช่าง จากนั้นจึงเริ่มเดินทาง อัปเดตสถานะ แชร์ GPS และดำเนินขั้นตอนให้บริการตามระบบ

การคำนวณระยะทางของฟีดงานเป็นระยะเส้นตรงระหว่างพิกัด ไม่ใช่ระยะทางขับรถหรือเวลาเดินทางจริง ช่างควรเปิด Google Maps เพื่อตรวจเส้นทางถนนก่อนออกเดินทาง

หากบัญชีช่างยังไม่มีโปรไฟล์ ระบบสร้างโปรไฟล์พื้นฐานที่ยังไม่ผ่านการยืนยันให้เมื่อเปิดหน้า “งานใกล้ฉัน” โดยใช้ราคาตั้งต้น 550 บาทและระบุพื้นที่ว่า “ยังไม่ระบุพื้นที่ให้บริการ” ช่างแก้ชื่อบริการ ราคาพื้นฐาน พื้นที่ ช่วงเวลา และทักษะได้เองที่เมนู **โปรไฟล์และราคา** ส่วนสถานะ “ตรวจสอบแล้ว” Admin เป็นผู้กำหนดหลังตรวจทานโปรไฟล์ คะแนนรีวิวและจำนวนงานที่สำเร็จระบบคำนวณให้อัตโนมัติ (จำนวนงานเพิ่มขึ้นเมื่อทั้งสองฝ่ายยืนยันการชำระเงินแล้ว)

## 4. สถานะงาน

ลำดับสถานะหลักของคำขอ:

`เปิดรับช่าง → รอเลือกช่าง → ยืนยันแล้ว → กำลังเดินทาง → ถึงหน้างาน → กำลังดำเนินการ → รอชำระเงิน → เสร็จสิ้น`

- **เปิดรับช่าง:** ลูกค้าสร้างคำขอแล้ว ยังไม่มีช่างส่งความสนใจ
- **รอเลือกช่าง:** มีช่างส่งความสนใจอย่างน้อยหนึ่งคน ลูกค้ากำลังเปรียบเทียบข้อเสนอ
- **ยืนยันแล้ว:** ลูกค้าเลือกช่างและยืนยันข้อเสนอแล้ว
- **กำลังเดินทาง / ถึงหน้างาน / กำลังดำเนินการ:** ช่างอัปเดตความคืบหน้าของงาน
- **รอชำระเงิน:** รอการยืนยันการชำระเงินหน้างานจากผู้เกี่ยวข้อง
- **เสร็จสิ้น:** ทั้งสองฝ่ายยืนยันครบตามขั้นตอนการชำระเงินที่ระบบกำหนด

## 5. ความเป็นส่วนตัวของตำแหน่ง

ฟีดงานสำหรับช่างแสดงเฉพาะพื้นที่โดยประมาณและระยะห่าง ไม่ส่งชื่อลูกค้า บ้านเลขที่ หรือพิกัดที่แม่นยำผ่านรายการงานเปิดรับ และช่างแต่ละคนเห็นเฉพาะข้อเสนอของตัวเอง ไม่เห็นราคาที่ช่างคนอื่นเสนอ เมื่อช่างได้รับเลือกและยืนยันแล้ว รายละเอียดสถานที่จึงใช้สำหรับการเดินทางและให้บริการได้ตามสิทธิ์ของบัญชีนั้น

## 6. ฟังก์ชันเสริมและบทบาทอื่น

- **Aircon Passport:** เก็บประวัติการดูแลเครื่องแอร์และรอบบำรุงรักษา เป็นฟังก์ชันเสริม ไม่จำเป็นต้องสร้างทะเบียนเครื่องก่อนขอรับบริการ ลูกค้าเพิ่ม/ลบเครื่องได้ที่ **แอร์ของฉัน** และเลือกเครื่องตอนส่งคำขอ (หรือกด “ขอช่างล้างเครื่องนี้”) เมื่องานเสร็จ ระบบบันทึกประวัติพร้อมสรุปจากรายงานช่าง และตั้งรอบถัดไปอีก 6 เดือน
- **รายงานบริการ:** บันทึกรายการตรวจเช็กและสรุปงานหลังให้บริการ ส่งได้หนึ่งฉบับต่องาน
- **รีวิว:** ลูกค้าให้คะแนนได้หลังงานเสร็จสิ้นเท่านั้น และรีวิวได้ครั้งเดียวต่องาน
- **งานหลายเครื่อง / Manager:** รองรับกรณีผู้ดูแลอาคารต้องนัดหมายแอร์หลายเครื่อง
- **Admin:** บทบาทผู้ดูแลระบบ ไม่สามารถเลือกสมัครเป็น Admin ผ่านหน้าลงทะเบียนสาธารณะได้ (สร้างบัญชีแรกด้วย `INITIAL_ADMIN_EMAIL` / `INITIAL_ADMIN_PASSWORD`) Admin กด “ยืนยันโปรไฟล์” หรือ “ยกเลิกการยืนยัน” ช่างได้ที่หน้า **ค้นหาช่าง**
- **ชำระเงิน:** เวอร์ชันปัจจุบันบันทึกการยืนยันของลูกค้าและช่าง ยังไม่ตรวจสอบธุรกรรมกับธนาคารหรือ Payment Gateway อัตโนมัติ

## 7. เทคโนโลยี

- Frontend: React 18, TypeScript, Vite
- แผนที่: Leaflet และ OpenStreetMap
- Backend: ASP.NET Core 8 Web API
- Database: MongoDB Atlas
- Authentication: JWT และการจัดเก็บรหัสผ่านแบบ hash
- Deployment target: Render สำหรับ Frontend และ Backend

## 8. API ของตลาดงาน

- `POST /api/bookings` — ลูกค้าสร้างคำขอโดยยังไม่ระบุช่าง
- `GET /api/technician-jobs?latitude=...&longitude=...&radiusKm=25` — ช่างค้นหางานตามตำแหน่งและระยะค้นหา
- `POST /api/bookings/{id}/applications` — ช่างส่งความสนใจรับงานและข้อเสนอราคา
- `POST /api/bookings/{id}/confirm-technician` — ลูกค้ายืนยันช่างจากผู้ที่ส่งความสนใจ
- `GET /api/bookings` — ดูรายการจองตามสิทธิ์ของบัญชี
- `PATCH /api/bookings/{id}/status` — เปลี่ยนสถานะงานตามขั้นตอนและสิทธิ์
- `POST /api/bookings/{id}/location` — ช่างอัปเดตตำแหน่งระหว่างเดินทาง
- `POST /api/bookings/{id}/reviews` — ลูกค้าให้คะแนนช่างหลังงานเสร็จ
- `GET/PATCH /api/technicians/me` — ช่างดูและแก้ไขโปรไฟล์บริการ ราคา และพื้นที่ของตน
- `PATCH /api/technicians/{id}/verification` — Admin ยืนยันหรือยกเลิกการยืนยันโปรไฟล์ช่าง
- `GET/POST /api/air-conditioners`, `DELETE /api/air-conditioners/{id}` — ลูกค้าจัดการเครื่องใน Aircon Passport (`POST /api/bookings` รับ `airConditionerId` ได้แบบไม่บังคับ)

## 9. สิ่งที่ควรทราบก่อนใช้งานจริง

- การค้นหางานใกล้ตัวต้องอนุญาต GPS บนอุปกรณ์ และต้องมีโปรไฟล์ช่างเชื่อมกับบัญชีผู้ใช้
- ราคาที่เห็นในขั้นตอนแรกเป็นราคาเริ่มต้นโดยประมาณ ลูกค้าควรตรวจสอบข้อเสนอราคาจากช่างก่อนกดยืนยัน
- การคำนวณระยะทางเป็นเส้นตรง ยังไม่ใช่ระบบค้นหาเส้นทางตามถนนหรือ ETA แบบเรียลไทม์
- Saved addresses ถูกเก็บใน Local Storage ของเบราว์เซอร์ และยังไม่ซิงก์ระหว่างอุปกรณ์
- การยืนยัน PromptPay ในระบบยังเป็นเพียงการบันทึกการยืนยัน ไม่ได้ตรวจสอบการโอนเงินจริง
- การสมัครเป็นช่างหรือผู้ดูแลอาคารยังเลือกได้เองตอนลงทะเบียน ควรให้ Admin ตรวจและกดยืนยันโปรไฟล์ช่างก่อนเปิดบริการจริง
- ก่อนเปิดให้บริการจริง ควรทดสอบเส้นทางครบทั้งลูกค้าและช่าง ตรวจสอบสิทธิ์/ความเป็นส่วนตัว และยืนยันสถานะการ Deploy บน Render อีกครั้ง

## 10. สรุป

AirClean ทำงานตามแนวคิด **ลูกค้าส่งคำขอ → ช่างใกล้เคียงส่งความสนใจและเสนอราคา → ลูกค้าเลือกยืนยันช่าง → ช่างเดินทางและให้บริการ** จุดสำคัญคือความสะดวกของลูกค้า ความชัดเจนของข้อเสนอสำหรับช่าง และการไม่เผยตำแหน่งบ้านที่แม่นยำก่อนลูกค้ายืนยันช่าง ส่วนสมุดประวัติแอร์และงานหลายเครื่องเป็นฟังก์ชันเสริมที่ช่วยให้ระบบขยายต่อได้ในอนาคต
