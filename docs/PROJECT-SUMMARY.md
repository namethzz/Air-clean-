# AirClean — สรุปแนวคิดและการทำงานของโปรเจกต์

## 1. แนวคิดหลัก

AirClean เป็นแพลตฟอร์มช่วยให้ลูกค้าหาช่างล้างแอร์จากพื้นที่ใกล้เคียง โดยใช้รูปแบบ **ตลาดงานใกล้ตัว (Marketplace) แบบ B** ลูกค้าไม่จำเป็นต้องตัดสินใจเลือกช่างตั้งแต่เริ่ม แต่ส่งคำขอพร้อมรายละเอียดงานก่อน จากนั้นช่างที่อยู่ในระยะค้นหาสามารถส่งความสนใจและเสนอราคา ลูกค้าเปรียบเทียบโปรไฟล์และราคา แล้วกดยืนยันช่างที่ต้องการด้วยตนเอง

หลักการออกแบบคือให้การจองของลูกค้าสั้นและเข้าใจง่าย ขณะเดียวกันช่างควรรู้รายละเอียดสำคัญก่อนสนใจงาน เช่น ระยะทางโดยประมาณ ประเภทที่พัก จำนวนเครื่อง วันนัดหมาย และราคาประเมิน

## 2. ขั้นตอนของลูกค้า (Customer)

0. สมัครหรือเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน หรือกด **เข้าสู่ระบบด้วย Google / Apple** ครั้งแรกระบบจะให้เลือกบทบาทก่อนสร้างบัญชี
1. เปิดคำขอใช้บริการ โดยเลือกตำแหน่งจากแผนที่หรือใช้ GPS แล้วกรอก/แก้ไขที่อยู่ บ้านเลขที่ อาคาร ชั้น ห้อง และจุดสังเกตได้
2. ระบุบริการ จำนวนเครื่อง รายละเอียดแอร์ วันที่และเวลาที่สะดวก
3. ส่งคำขอให้ช่างใกล้เคียง โดยไม่ต้องเลือกช่างล่วงหน้า
4. รอช่างส่งความสนใจ เมื่อมีข้อเสนอจะเห็นคะแนนรีวิว ประสบการณ์ พื้นที่ให้บริการ และราคาที่เสนอ
5. เปรียบเทียบข้อเสนอและกดยืนยันช่างหนึ่งคน เมื่อยืนยันแล้วงานจึงผูกกับช่างคนนั้น
6. ดูสถานะงาน เปิดแผนที่/Google Maps และติดตามตำแหน่งช่างเมื่อช่างเริ่มเดินทางและแชร์ GPS
7. หลังบริการ ตรวจรายงาน แล้ว **จ่ายเงินปลายทาง** ให้ช่างโดยตรง (เงินสดหรือโอนให้ช่าง) และกดยืนยันว่าชำระแล้ว ไม่มีการจ่ายเงินล่วงหน้า
8. เมื่องานเสร็จสิ้น ให้คะแนนช่าง 1–5 ดาวพร้อมความเห็นได้หนึ่งครั้งต่องาน คะแนนเฉลี่ยและจำนวนรีวิวของช่างจะอัปเดตทันที และแสดงในข้อเสนอของงานถัดไป

คำขอยังสามารถยกเลิกได้ในช่วงเปิดรับช่างหรือรอเลือกช่าง ตามกฎที่กำหนดใน API

## 3. ขั้นตอนของช่าง (Technician)

1. สมัครเป็นช่างโดยกรอกเบอร์โทร พื้นที่ให้บริการ และประสบการณ์ แล้วรอ Admin ตรวจสอบและอนุมัติ ระหว่างนี้หน้า **งานใกล้ฉัน** จะแสดงสถานะ “รอผู้ดูแลระบบตรวจสอบ” ถ้าไม่ผ่านจะเห็นเหตุผล แก้ข้อมูลในโปรไฟล์แล้วระบบส่งตรวจอีกครั้งให้อัตโนมัติ
2. เมื่ออนุมัติแล้ว เปิดเมนู **งานใกล้ฉัน** และอนุญาตให้เว็บไซต์เข้าถึง GPS
3. เลือกระยะค้นหาที่ต้องการได้ เช่น 5, 10, 25, 50 หรือ 100 กิโลเมตร
4. ดูงานที่เรียงจากใกล้ไปไกล พร้อมประเภทที่พัก จำนวนเครื่อง รายละเอียดบริการ วันและเวลา และราคาประเมิน
5. กดสนใจรับงานเพื่อส่งข้อเสนอพร้อมราคาที่คำนวณจากราคาพื้นฐานของช่างและรายละเอียดงาน
6. รอลูกค้าตรวจสอบโปรไฟล์และยืนยันช่าง การกดสนใจยังไม่เท่ากับได้รับมอบหมายงาน
7. เมื่อได้รับการยืนยัน งานจะปรากฏในรายการงานของช่าง จากนั้นจึงเริ่มเดินทาง อัปเดตสถานะ แชร์ GPS และดำเนินขั้นตอนให้บริการตามระบบ
8. ล้างเสร็จแล้วเก็บเงินปลายทางจากลูกค้า ตรวจยอดถ้าลูกค้าโอน แล้วกด “ฉันได้รับเงินแล้ว”

การคำนวณระยะทางของฟีดงานเป็นระยะเส้นตรงระหว่างพิกัด ไม่ใช่ระยะทางขับรถหรือเวลาเดินทางจริง ช่างควรเปิด Google Maps เพื่อตรวจเส้นทางถนนก่อนออกเดินทาง

ระบบสร้างโปรไฟล์ช่างสถานะ “รอตรวจสอบ” ให้ตั้งแต่สมัคร โดยใช้ราคาตั้งต้น 550 บาท ช่างแก้ชื่อบริการ ราคาพื้นฐาน พื้นที่ ช่วงเวลา ทักษะ เบอร์โทร และประสบการณ์ได้เองที่เมนู **โปรไฟล์และราคา** (เบอร์โทรใช้สำหรับ Admin ติดต่อ ไม่แสดงต่อลูกค้า) ช่างที่ยังไม่อนุมัติจะไม่ปรากฏในรายชื่อช่างสาธารณะ ไม่เห็นงาน และส่งข้อเสนอไม่ได้ คะแนนรีวิวและจำนวนงานที่สำเร็จระบบคำนวณให้อัตโนมัติ (จำนวนงานเพิ่มขึ้นเมื่อทั้งสองฝ่ายยืนยันการชำระเงินแล้ว)

## 4. สถานะงาน

ลำดับสถานะหลักของคำขอ:

`เปิดรับช่าง → รอเลือกช่าง → ยืนยันแล้ว → กำลังเดินทาง → ถึงหน้างาน → กำลังดำเนินการ → รอชำระเงิน → เสร็จสิ้น`

- **เปิดรับช่าง:** ลูกค้าสร้างคำขอแล้ว ยังไม่มีช่างส่งความสนใจ
- **รอเลือกช่าง:** มีช่างส่งความสนใจอย่างน้อยหนึ่งคน ลูกค้ากำลังเปรียบเทียบข้อเสนอ
- **ยืนยันแล้ว:** ลูกค้าเลือกช่างและยืนยันข้อเสนอแล้ว
- **กำลังเดินทาง / ถึงหน้างาน / กำลังดำเนินการ:** ช่างอัปเดตความคืบหน้าของงาน
- **รอชำระเงิน:** ล้างเสร็จแล้ว รอลูกค้าจ่ายเงินปลายทางให้ช่างและกดยืนยันทั้งสองฝ่าย
- **เสร็จสิ้น:** ทั้งสองฝ่ายยืนยันครบตามขั้นตอนการชำระเงินที่ระบบกำหนด

## 5. ความเป็นส่วนตัวของตำแหน่ง

ฟีดงานสำหรับช่างแสดงเฉพาะพื้นที่โดยประมาณและระยะห่าง ไม่ส่งชื่อลูกค้า บ้านเลขที่ หรือพิกัดที่แม่นยำผ่านรายการงานเปิดรับ และช่างแต่ละคนเห็นเฉพาะข้อเสนอของตัวเอง ไม่เห็นราคาที่ช่างคนอื่นเสนอ เมื่อช่างได้รับเลือกและยืนยันแล้ว รายละเอียดสถานที่จึงใช้สำหรับการเดินทางและให้บริการได้ตามสิทธิ์ของบัญชีนั้น

## 6. ฟังก์ชันเสริมและบทบาทอื่น

- **Aircon Passport:** เก็บประวัติการดูแลเครื่องแอร์และรอบบำรุงรักษา เป็นฟังก์ชันเสริม ไม่จำเป็นต้องสร้างทะเบียนเครื่องก่อนขอรับบริการ ลูกค้าเพิ่ม/ลบเครื่องได้ที่ **แอร์ของฉัน** และเลือกเครื่องตอนส่งคำขอ (หรือกด “ขอช่างล้างเครื่องนี้”) เมื่องานเสร็จ ระบบบันทึกประวัติพร้อมสรุปจากรายงานช่าง และตั้งรอบถัดไปอีก 6 เดือน
- **รายงานบริการ:** บันทึกรายการตรวจเช็กและสรุปงานหลังให้บริการ ส่งได้หนึ่งฉบับต่องาน
- **รีวิว:** ลูกค้าให้คะแนนได้หลังงานเสร็จสิ้นเท่านั้น และรีวิวได้ครั้งเดียวต่องาน
- **งานหลายเครื่อง / Manager:** รองรับกรณีผู้ดูแลอาคารต้องนัดหมายแอร์หลายเครื่อง
- **Admin:** บทบาทผู้ดูแลระบบ ไม่สามารถเลือกสมัครเป็น Admin ผ่านหน้าลงทะเบียนสาธารณะได้ (สร้างบัญชีแรกด้วย `INITIAL_ADMIN_EMAIL` / `INITIAL_ADMIN_PASSWORD`) Admin ตรวจสอบช่างที่หน้า **ตรวจสอบช่าง**: ดูชื่อ เบอร์โทร (กดโทรได้) อีเมล พื้นที่ ประสบการณ์ และราคา แล้วกด **อนุมัติ** หรือ **ไม่ผ่าน** พร้อมเหตุผล และ **ระงับการรับงาน** ช่างที่อนุมัติไปแล้วได้
- **ชำระเงิน — เก็บเงินปลายทาง:** ลูกค้าจ่ายช่างโดยตรงเมื่อล้างเสร็จ ด้วยเงินสดหรือโอนให้ช่าง ทั้งสองฝ่ายกดยืนยันแล้วงานจึงปิด AirClean ไม่เก็บเงินล่วงหน้าและไม่รับเงินแทนช่าง หากมีปัญหากด “แจ้งปัญหาการชำระเงิน” ให้ Admin ตรวจสอบ
- **บัญชีและรหัสผ่าน:** กด “ลืมรหัสผ่าน?” ที่หน้าเข้าสู่ระบบ ระบบส่งลิงก์ทางอีเมล (ใช้ได้ครั้งเดียว ภายใน 30 นาที) ถ้าไม่ได้รับอีเมล Admin สร้างลิงก์ (ใช้ได้ 24 ชั่วโมง) ที่หน้า **ตรวจสอบช่าง** แล้วส่งให้ผู้ใช้หลังยืนยันตัวตนทางโทรศัพท์ เปลี่ยนรหัสผ่านได้ที่หน้าโปรไฟล์ เมื่อรีเซ็ตหรือเปลี่ยนรหัสผ่าน อุปกรณ์อื่นที่เข้าสู่ระบบไว้จะถูกออกจากระบบ
- **เข้าสู่ระบบด้วย Google และ Apple:** เซิร์ฟเวอร์ตรวจลายเซ็นของโทเคนจาก Google/Apple ว่าออกให้แอปของเราจริงและยังไม่หมดอายุ ถ้าอีเมลที่ Google/Apple ยืนยันแล้วตรงกับบัญชีเดิม ระบบจะเชื่อมเข้าบัญชีนั้น ถ้ายังไม่มีบัญชีจะให้เลือกบทบาทก่อน (ช่างต้องกรอกเบอร์โทรและพื้นที่ และรอ Admin อนุมัติเหมือนเดิม) บัญชี Admin เข้าได้ด้วยรหัสผ่านเท่านั้น บัญชีที่สมัครด้วย Google/Apple ตั้งรหัสผ่านเพิ่มได้ที่หน้าโปรไฟล์
- **แจ้งเตือนทางอีเมล:** ลูกค้าได้รับอีเมลเมื่อมีช่างเสนอราคา ช่างเริ่มเดินทาง ล้างเสร็จ (พร้อมยอดเก็บเงินปลายทาง) และงานเสร็จสมบูรณ์ ช่างได้รับอีเมลเมื่อลูกค้ายืนยัน (พร้อมที่อยู่) ไม่ได้รับเลือก ผลการอนุมัติ และเมื่อลูกค้ายกเลิก Admin ได้รับอีเมลเมื่อมีช่างสมัครใหม่และมีการแจ้งปัญหาการชำระเงิน ผู้ใช้ปิดการแจ้งเตือนได้ที่หน้าโปรไฟล์ (อีเมลลืมรหัสผ่านยังส่งเสมอ)
- **ที่อยู่ที่บันทึกไว้:** เก็บในบัญชีผู้ใช้ (สูงสุด 20 รายการ) จึงเห็นเหมือนกันทุกเครื่อง ที่อยู่ที่เคยบันทึกไว้ในเบราว์เซอร์ระบบย้ายเข้าบัญชีให้อัตโนมัติ

## 7. เทคโนโลยี

- Frontend: React 18, TypeScript, Vite
- แผนที่: Leaflet และ OpenStreetMap
- Backend: ASP.NET Core 8 Web API
- Database: MongoDB Atlas
- Authentication: JWT และการจัดเก็บรหัสผ่านแบบ hash
- Deployment target: Render สำหรับ Frontend และ Backend

## 8. API ของตลาดงาน

- `POST /api/bookings` — ลูกค้าสร้างคำขอโดยยังไม่ระบุช่าง
- `GET /api/technician-jobs?latitude=...&longitude=...&radiusKm=25` — ช่างค้นหางานตามตำแหน่งและระยะค้นหา
- `POST /api/bookings/{id}/applications` — ช่างส่งความสนใจรับงานและข้อเสนอราคา
- `POST /api/bookings/{id}/confirm-technician` — ลูกค้ายืนยันช่างจากผู้ที่ส่งความสนใจ
- `GET /api/bookings` — ดูรายการจองตามสิทธิ์ของบัญชี
- `PATCH /api/bookings/{id}/status` — เปลี่ยนสถานะงานตามขั้นตอนและสิทธิ์
- `POST /api/bookings/{id}/location` — ช่างอัปเดตตำแหน่งระหว่างเดินทาง
- `POST /api/bookings/{id}/reviews` — ลูกค้าให้คะแนนช่างหลังงานเสร็จ
- `GET/PATCH /api/technicians/me` — ช่างดูและแก้ไขโปรไฟล์บริการ ราคา พื้นที่ เบอร์โทร และดูสถานะการตรวจสอบ
- `GET /api/admin/technicians?status=Pending` — Admin ดูคิวช่างที่รอตรวจสอบ
- `PATCH /api/technicians/{id}/verification` — Admin อนุมัติ (`verified: true`) หรือไม่ผ่าน/ระงับ (`verified: false` พร้อม `note`)
- `POST /api/auth/forgot-password`, `POST /api/auth/reset-password`, `POST /api/auth/change-password` — ลืม/ตั้ง/เปลี่ยนรหัสผ่าน
- `POST /api/admin/password-reset-links` — Admin สร้างลิงก์ตั้งรหัสผ่านใหม่ให้ผู้ใช้
- `POST /api/auth/external` — เข้าสู่ระบบ/สมัครด้วย Google หรือ Apple (ส่ง ID token จากผู้ให้บริการ)
- `GET/POST /api/me/addresses`, `DELETE /api/me/addresses/{id}` — ที่อยู่ที่บันทึกไว้ของบัญชี
- `GET/POST /api/air-conditioners`, `DELETE /api/air-conditioners/{id}` — ลูกค้าจัดการเครื่องใน Aircon Passport (`POST /api/bookings` รับ `airConditionerId` ได้แบบไม่บังคับ)

## 9. สิ่งที่ควรทราบก่อนใช้งานจริง

- การค้นหางานใกล้ตัวต้องอนุญาต GPS บนอุปกรณ์ และต้องมีโปรไฟล์ช่างเชื่อมกับบัญชีผู้ใช้
- ราคาที่เห็นในขั้นตอนแรกเป็นราคาเริ่มต้นโดยประมาณ ลูกค้าควรตรวจสอบข้อเสนอราคาจากช่างก่อนกดยืนยัน
- การคำนวณระยะทางเป็นเส้นตรง ยังไม่ใช่ระบบค้นหาเส้นทางตามถนนหรือ ETA แบบเรียลไทม์
- เปิดใช้ Google: สร้าง OAuth Client ID ประเภท Web application ใน Google Cloud Console ใส่ Authorized JavaScript origins เป็นที่อยู่เว็บ แล้วตั้ง `GOOGLE_CLIENT_ID` (API) และ `VITE_GOOGLE_CLIENT_ID` (Static Site) เป็นค่าเดียวกัน
- เปิดใช้ Apple: ต้องมี Apple Developer Program (เสียค่าบริการรายปี) สร้าง Services ID เปิด Sign in with Apple ใส่โดเมนและ Return URL ของเว็บ แล้วตั้ง `APPLE_CLIENT_ID` และ `VITE_APPLE_CLIENT_ID`
- หน้านโยบายความเป็นส่วนตัว `/privacy.html` และข้อกำหนดการใช้งาน `/terms.html` มีลิงก์จากหน้าแรกและหน้าเข้าสู่ระบบ ใช้กรอกใน Google Auth Platform → Branding อีเมลติดต่อบนหน้านี้ตั้งด้วย `VITE_CONTACT_EMAIL` บน Static Site เนื้อหาเป็นร่างเริ่มต้น ควรตรวจทานก่อนเปิดใช้จริง
- ตั้งค่าการส่งอีเมล: Render แพลนฟรีบล็อกการเชื่อมต่อ SMTP จึงใช้ `BREVO_API_KEY` (ส่งผ่าน HTTPS) คู่กับ `SMTP_FROM` แล้วตรวจด้วยปุ่ม **ส่งอีเมลทดสอบ** ในหน้าตรวจสอบช่าง ค่า `SMTP_HOST` และอื่นๆ ใช้เฉพาะเมื่อไม่ได้ตั้ง `BREVO_API_KEY`
- หลัง deploy ให้ตรวจคิว **ตรวจสอบช่าง** เพราะโปรไฟล์ช่างเดิมที่ยังไม่เคยยืนยันจะกลายเป็น “รอตรวจสอบ”
- บัญชีผู้ดูแลอาคาร (Manager) ยังเลือกสมัครได้เองตอนลงทะเบียน
- ก่อนเปิดให้บริการจริง ควรทดสอบเส้นทางครบทั้งลูกค้าและช่าง ตรวจสอบสิทธิ์/ความเป็นส่วนตัว และยืนยันสถานะการ Deploy บน Render อีกครั้ง

## 10. สรุป

AirClean ทำงานตามแนวคิด **ลูกค้าส่งคำขอ → ช่างใกล้เคียงส่งความสนใจและเสนอราคา → ลูกค้าเลือกยืนยันช่าง → ช่างเดินทางและให้บริการ** จุดสำคัญคือความสะดวกของลูกค้า ความชัดเจนของข้อเสนอสำหรับช่าง และการไม่เผยตำแหน่งบ้านที่แม่นยำก่อนลูกค้ายืนยันช่าง ส่วนสมุดประวัติแอร์และงานหลายเครื่องเป็นฟังก์ชันเสริมที่ช่วยให้ระบบขยายต่อได้ในอนาคต
