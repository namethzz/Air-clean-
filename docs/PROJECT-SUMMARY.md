# AirClean — สรุปแนวคิดและการทำงานของโปรเจกต์

## 1. แนวคิดหลัก

AirClean เป็นแพลตฟอร์มช่วยให้ลูกค้าหาช่างล้างแอร์จากพื้นที่ใกล้เคียง ในรูปแบบ **ตลาดงานใกล้ตัว (Marketplace)** ลูกค้าไม่ต้องเลือกช่างตั้งแต่เริ่ม แต่ส่งคำขอพร้อมรายละเอียดงานก่อน จากนั้นช่างที่อยู่ในระยะค้นหาเสนอราคาเข้ามา ลูกค้าเปรียบเทียบโปรไฟล์และราคา แล้วกดยืนยันช่างที่ต้องการเองภายใน 1 ชั่วโมงนับจากข้อเสนอแรก

หลักการออกแบบคือให้การจองของลูกค้าสั้นและเข้าใจง่าย ขณะเดียวกันช่างควรรู้รายละเอียดสำคัญก่อนเสนอราคา เช่น ระยะทางโดยประมาณ ประเภทที่พัก ชนิดและจำนวนเครื่อง วันนัดหมาย และราคาที่คำนวณจากใบราคาของช่างเอง

AirClean ไม่เก็บค่าคอมมิชชันต่องาน รายได้มาจากค่าสมาชิกรายเดือนของช่าง (จ่ายผ่าน QR พร้อมเพย์ และระบบตรวจสลิปกับธนาคารอัตโนมัติ) ส่วนค่าล้างแอร์ลูกค้าจ่ายให้ช่างโดยตรงที่หน้างาน

## 2. ขั้นตอนของลูกค้า (Customer)

0. สมัครหรือเข้าสู่ระบบด้วยอีเมลและรหัสผ่าน หรือกด **เข้าสู่ระบบด้วย Google** ครั้งแรกระบบจะให้เลือกบทบาทก่อนสร้างบัญชี
1. เปิดคำขอใช้บริการ โดยเลือกตำแหน่งจากแผนที่หรือใช้ GPS แล้วกรอก/แก้ไขที่อยู่ บ้านเลขที่ อาคาร ชั้น ห้อง และจุดสังเกตได้
2. บอกสิ่งที่มองเห็นได้ ไม่ต้องรู้ราคาหรือ BTU: ชนิดแอร์ (ติดผนัง แขวน/ตั้งพื้น ฝังฝ้า) จำนวนเครื่อง ตัวใหญ่กี่เครื่อง ล้างธรรมดาหรือล้างใหญ่ คอยล์ร้อนที่เข้าถึงยาก ล้างครั้งล่าสุดเมื่อไร อาการ (น้ำหยด ไม่เย็น มีกลิ่น เสียงดัง) และวันเวลาที่สะดวก (เวลาเดียวหรือเป็นช่วง) ฟอร์มแสดงราคากลางที่ช่างส่วนใหญ่คิดสำหรับงานนี้ทันที
3. ส่งคำขอให้ช่างใกล้เคียง โดยไม่ต้องเลือกช่างล่วงหน้า
4. รอช่างเสนอราคา เมื่อมีข้อเสนอจะเห็นรูป คะแนนรีวิว จำนวนงานที่ทำ พื้นที่ให้บริการ ราคาแยกรายบรรทัด และป้ายบอกว่าราคานี้ต่ำ ปกติ หรือสูงกว่าราคากลาง ระบบนับถอยหลัง 1 ชั่วโมงจากข้อเสนอแรก และเตือนก่อนหมดเวลา 20 นาที
5. เปรียบเทียบข้อเสนอและกดยืนยันช่างหนึ่งคน เมื่อยืนยันแล้วงานจึงผูกกับช่างคนนั้นและราคาล็อก ถ้าไม่ได้เลือกภายในเวลา ข้อเสนอหมดอายุ และกดเปิดรับช่างใหม่ได้ในปุ่มเดียว
6. ดูสถานะงาน โทรหาช่าง เปลี่ยนวันนัดหลังโทรตกลงกันแล้ว เปิดแผนที่/Google Maps และติดตามตำแหน่งช่างเมื่อช่างเริ่มเดินทางและแชร์ GPS ถ้าช่างขอปรับราคาหน้างาน ลูกค้าเห็นเหตุผลและยอดใหม่ แล้วกดอนุมัติหรือปฏิเสธ
7. หลังล้างเสร็จ **จ่ายเงินปลายทาง** ให้ช่างโดยตรง (เงินสดหรือโอน) ช่างกดปิดงานว่าได้รับเงินแล้ว ลูกค้ากดยืนยัน หรือกดแจ้งปัญหาการชำระเงินถ้ายอดไม่ตรงหรือยังไม่ได้จ่าย ถ้าลูกค้าไม่ทำอะไรภายใน 3 วัน ระบบปิดงานให้เอง
8. เมื่องานเสร็จ หน้างานแสดงสรุปการจ่ายเงิน ให้คะแนนช่าง 1–5 ดาว แล้วแสดงขั้นต่อไป: รอบล้างถัดไปที่แนะนำ ขอช่างอีกครั้ง บันทึกแอร์ไว้ใน “แอร์ของฉัน” และปุ่ม “มีปัญหากับงานนี้” (ภายใน 14 วัน) ให้คะแนนได้หนึ่งครั้งต่องาน คะแนนเฉลี่ยและจำนวนรีวิวของช่างจะอัปเดตทันที และแสดงในข้อเสนอของงานถัดไป

ลูกค้ายกเลิกคำขอได้ตอนเปิดรับช่าง รอเลือกช่าง ข้อเสนอหมดอายุ และหลังยืนยันช่างแล้วแต่ช่างยังไม่ออกเดินทาง (ช่างที่ได้รับเลือกยกเลิกได้ในช่วงเดียวกัน) หลังช่างออกเดินทางแล้วทั้งสองฝ่ายยกเลิกในแอปไม่ได้ ต้องโทรคุยกันหรือให้แอดมินเปลี่ยนสถานะให้

## 3. ขั้นตอนของช่าง (Technician)

1. สมัครเป็นช่าง แล้วตั้งค่างานทีละขั้น: ชนิดแอร์ที่รับล้าง รับล้างใหญ่หรือไม่ งานอื่นที่ทำได้ ราคาต่อเครื่อง (ระบบแสดงราคาที่ช่างส่วนใหญ่คิดไว้ข้างๆ) พื้นที่และเวลา เบอร์โทร และรูปบัตรประชาชนกับรูปถือบัตร จากนั้นกดส่งให้ Admin ตรวจ ระบบบอกว่ายังขาดอะไร และ Admin อนุมัติไม่ได้จนกว่าช่างจะส่งครบ ระหว่างรอ หน้า **งานใกล้ฉัน** แสดงสถานะ “รอผู้ดูแลระบบตรวจสอบ” ถ้าไม่ผ่านจะเห็นเหตุผล แก้ข้อมูลในโปรไฟล์แล้วระบบส่งตรวจอีกครั้งให้อัตโนมัติ
   หลังอนุมัติ ช่างใช้งานฟรีช่วงทดลอง (ตั้งต้น 30 วัน) จากนั้นต่ออายุสมาชิกรายเดือนที่หน้า **สมาชิก AirClean** ด้วย QR พร้อมเพย์แล้วแนบสลิป สมาชิกหมดอายุแล้วส่งข้อเสนองานใหม่ไม่ได้ แต่งานที่รับไว้แล้วทำต่อได้ตามปกติ
2. เมื่ออนุมัติแล้ว เปิดเมนู **งานใกล้ฉัน** และอนุญาตให้เว็บไซต์เข้าถึง GPS
3. เลือกระยะค้นหาที่ต้องการได้ เช่น 5, 10, 25, 50 หรือ 100 กิโลเมตร
4. ดูงานที่เรียงจากใกล้ไปไกล พร้อมประเภทที่พัก ชนิดและจำนวนเครื่อง รายละเอียดบริการ วันและเวลา และราคาที่จะได้ตามใบราคาของตัวเอง ระบบแสดงเฉพาะงานที่ช่างรับทำ เช่น ช่างที่ไม่รับแอร์ฝังฝ้าจะไม่เห็นงานที่มีแอร์ฝังฝ้า
5. กดเสนอราคา ระบบคิดราคาจากใบราคาของช่างเป็นรายบรรทัด ช่างพิมพ์ยอดรวมเองไม่ได้ และใบราคาที่ใช้ตอนเสนอถูกเก็บไว้กับข้อเสนอ ช่างแก้ใบราคาทีหลังก็ไม่กระทบงานนี้
6. รอลูกค้าตรวจสอบโปรไฟล์และยืนยันช่าง การกดสนใจยังไม่เท่ากับได้รับมอบหมายงาน
7. หลังกดสนใจ ระบบพาไปที่งานนั้นใน “งานของฉัน” ทันที (สถานะรอลูกค้าเลือก) เมื่อลูกค้าเลือก หน้าเดียวกันจะเปลี่ยนเป็น “งานที่ต้องไป” พร้อมที่อยู่ แผนที่ และปุ่มนำทาง การกด “ออกเดินทาง” เพื่อให้ลูกค้าเห็นตำแหน่งเป็นทางเลือก และเมื่อถึงหน้างานระบบรู้เองจาก GPS
8. ระหว่างทำงาน ถ้าแอร์จริงไม่ตรงกับที่ลูกค้าบอก ช่างกดขอแก้รายการ ระบบคิดราคาใหม่จากใบราคาเดิม ถ้ามีงานเพิ่ม (เติมน้ำยา เปลี่ยนอะไหล่) ช่างใส่ราคาและเหตุผลเอง ทั้งสองแบบมีผลเมื่อลูกค้าอนุมัติเท่านั้น งานหลายห้องติ๊กห้องที่เสร็จได้ทีละห้อง และแนบรูปก่อนและหลังล้างได้
9. ล้างเสร็จและรับเงินแล้ว กด **“งานเสร็จและได้รับเงินแล้ว”** ครั้งเดียว ระบบบันทึกการรับเงินและรายงาน (รายการที่ทำติ๊กไว้ให้แล้ว) แล้วรอลูกค้ายืนยัน เมื่อลูกค้ายืนยันหรือครบ 3 วันโดยไม่มีการแจ้งปัญหา งานจึงปิด จำนวนงานที่สำเร็จของช่างเพิ่มขึ้น และประวัติการล้างแอร์ของลูกค้าถูกบันทึก

การคำนวณระยะทางของฟีดงานเป็นระยะเส้นตรงระหว่างพิกัด ไม่ใช่ระยะทางขับรถหรือเวลาเดินทางจริง ช่างควรเปิด Google Maps เพื่อตรวจเส้นทางถนนก่อนออกเดินทาง

ระบบสร้างโปรไฟล์ช่างสถานะ “รอตรวจสอบ” ให้ตั้งแต่สมัคร ระหว่างตั้งค่า ช่องราคาแต่ละช่องแสดงราคาที่ช่างส่วนใหญ่ในระบบคิด (มัธยฐาน) ให้กดใช้หรือใส่ราคาของตัวเอง ถ้ามีช่างที่อนุมัติแล้วไม่ถึง 3 คน ระบบแสดงราคาอ้างอิงของ AirClean แทน (ติดผนัง 600 บาท ล้างใหญ่ 1,200 บาท แขวน/ตั้งพื้น 1,000 บาท ฝังฝ้า 1,200 บาท บวกเครื่องใหญ่ 200 บาทและจุดเข้าถึงยาก 300 บาทต่อเครื่อง) โปรไฟล์ที่สร้างก่อนมีใบราคายังมีราคาพื้นฐานเดียว (ตั้งต้น 550 บาท) ระบบแปลงเป็นใบราคาโดยเทียบสัดส่วนกับราคาอ้างอิง ช่างแก้ชื่อบริการ ใบราคา พื้นที่ ช่วงเวลา ทักษะ เบอร์โทร และประสบการณ์ได้เองที่เมนู **โปรไฟล์และราคา** (เบอร์โทรใช้สำหรับ Admin ติดต่อ ไม่แสดงต่อลูกค้า) ช่างที่ยังไม่อนุมัติจะไม่ปรากฏในรายชื่อช่างสาธารณะ ไม่เห็นงาน และส่งข้อเสนอไม่ได้ คะแนนรีวิวและจำนวนงานที่สำเร็จระบบคำนวณให้อัตโนมัติ (จำนวนงานเพิ่มขึ้นเมื่องานถึงสถานะเสร็จสิ้น)

## 4. สถานะงาน

ลำดับสถานะหลักของคำขอ:

`เปิดรับช่าง → รอเลือกช่าง → ยืนยันแล้ว → กำลังเดินทาง → ถึงหน้างาน → กำลังดำเนินการ → รอชำระเงิน → เสร็จสิ้น`

- **เปิดรับช่าง:** ลูกค้าสร้างคำขอแล้ว ยังไม่มีช่างเสนอราคา
- **รอเลือกช่าง:** มีช่างเสนอราคาอย่างน้อยหนึ่งคน ลูกค้ากำลังเปรียบเทียบ และมีเวลา 1 ชั่วโมงนับจากข้อเสนอแรก
- **ยืนยันแล้ว:** ลูกค้าเลือกช่างและยืนยันข้อเสนอแล้ว ราคาล็อก ช่างเห็นที่อยู่เต็มและเบอร์โทร
- **กำลังเดินทาง / ถึงหน้างาน / กำลังดำเนินการ:** ช่างอัปเดตความคืบหน้าของงาน ระบบรู้ว่าถึงหน้างานเมื่อ GPS ของช่างอยู่ห่างไม่เกินราว 150 เมตร
- **รอชำระเงิน:** ล้างเสร็จแล้ว รอยืนยันการจ่ายเงินปลายทางจากทั้งสองฝ่าย
- **เสร็จสิ้น:** ทั้งสองฝ่ายยืนยันแล้ว หรือช่างยืนยันแล้วและครบ 3 วันโดยลูกค้าไม่แจ้งปัญหา

สถานะนอกเส้นทางหลัก:

- **ข้อเสนอหมดอายุ:** ลูกค้าไม่เลือกช่างภายใน 1 ชั่วโมง ข้อเสนอทั้งหมดถูกปล่อย ลูกค้ากดเปิดรับช่างใหม่ได้
- **มีปัญหาการชำระเงิน:** ฝ่ายใดฝ่ายหนึ่งแจ้งว่ายอดไม่ตรงหรือยังไม่ได้จ่าย งานเข้าคิวให้ Admin ตัดสินว่าจ่ายแล้ว (ปิดงาน) หรือยกเลิก
- **ยกเลิก:** ลูกค้าหรือช่างยกเลิกก่อนออกเดินทาง Admin ยกเลิก หรือบัญชีของอีกฝ่ายถูกลบก่อนเริ่มงาน

## 5. ความเป็นส่วนตัวของตำแหน่ง

ฟีดงานสำหรับช่างแสดงเฉพาะพื้นที่โดยประมาณและระยะห่าง ไม่ส่งชื่อลูกค้า บ้านเลขที่ เบอร์โทร รายการห้อง หรือพิกัดที่แม่นยำผ่านรายการงานเปิดรับ และช่างแต่ละคนเห็นเฉพาะข้อเสนอของตัวเอง ไม่เห็นราคาที่ช่างคนอื่นเสนอ แม้แต่ช่างที่ได้รับเลือกแล้วก็ไม่เห็นว่าใครเสนอแข่งด้วยราคาเท่าไร (`TechnicianViewFilter`)

ระยะทางในฟีดไม่ได้วัดจากหมุดบ้านจริง ระบบสุ่มจุดที่ห่างจากบ้าน 300–700 เมตรครั้งเดียวตอนสร้างงานแล้วเก็บไว้ วัดระยะจากจุดนั้นแล้วปัดขึ้นเป็นกิโลเมตรเต็ม ช่างที่ลองค้นจากหลายตำแหน่งจึงหาบ้านลูกค้าไม่ได้ เมื่อช่างได้รับเลือกและยืนยันแล้ว รายละเอียดสถานที่จึงใช้สำหรับการเดินทางและให้บริการได้ตามสิทธิ์ของบัญชีนั้น

## 6. ฟังก์ชันเสริมและบทบาทอื่น

- **ประวัติการล้างแอร์:** ทุกงานที่เสร็จจะถูกเก็บไว้ที่หน้า **ประวัติการล้างแอร์** พร้อมรายการที่ช่างทำ รูปงาน ใบเสร็จ และวันที่ควรล้างครั้งถัดไป (6 เดือน) ระบบแจ้งเตือนเมื่อถึงรอบ (งานที่ผูกกับเครื่องแอร์จากระบบ Aircon Passport เดิมยังบันทึกประวัติลงเครื่องนั้นด้วย)
- **รายงานบริการ:** บันทึกรายการตรวจเช็กและสรุปงานหลังให้บริการ ส่งได้หนึ่งฉบับต่องาน
- **รีวิว:** ลูกค้าให้คะแนนได้หลังงานเสร็จสิ้นเท่านั้น และรีวิวได้ครั้งเดียวต่องาน
- **ผู้ดูแลอาคาร (Manager):** ตั้งรายการห้องของอาคารครั้งเดียว แล้วเลือกห้องที่จะล้างในแต่ละงาน ช่างติ๊กห้องที่ล้างเสร็จ และเห็นว่าห้องไหนถึงรอบล้าง
- **Admin:** บทบาทผู้ดูแลระบบ ไม่สามารถเลือกสมัครเป็น Admin ผ่านหน้าลงทะเบียนสาธารณะได้ (สร้างบัญชีแรกด้วย `INITIAL_ADMIN_EMAIL` / `INITIAL_ADMIN_PASSWORD`) Admin ตรวจสอบช่างที่หน้า **ตรวจสอบช่าง**: ดูชื่อ เบอร์โทร (กดโทรได้) อีเมล พื้นที่ ประสบการณ์ และราคา แล้วกด **อนุมัติ** หรือ **ไม่ผ่าน** พร้อมเหตุผล และ **ระงับการรับงาน** ช่างที่อนุมัติไปแล้วได้
- **ชำระเงิน — เก็บเงินปลายทาง:** ลูกค้าจ่ายช่างโดยตรงเมื่อล้างเสร็จ ด้วยเงินสดหรือโอนให้ช่าง ทั้งสองฝ่ายกดยืนยันแล้วงานจึงปิด (หรือช่างยืนยันแล้วครบ 3 วันโดยไม่มีการแจ้งปัญหา) AirClean ไม่เก็บเงินล่วงหน้าและไม่รับเงินแทนช่าง หากมีปัญหากด “แจ้งปัญหาการชำระเงิน” ให้ Admin ตรวจสอบ
- **ใบเสร็จ:** ลูกค้าออกใบเสร็จของงานที่จ่ายแล้วได้ พร้อมจำนวนเงินเป็นตัวอักษรภาษาไทย ออกในนามบริษัทพร้อมเลขผู้เสียภาษีและสาขาได้ (ระบบจำข้อมูลไว้ใช้ครั้งถัดไป) เลขใบเสร็จออกครั้งเดียวต่องาน กดซ้ำก็ได้เลขเดิม
- **ค่าสมาชิกช่าง:** Admin ตั้งค่าสมาชิกต่อเดือน (ตั้งต้น 299 บาท) จำนวนวันทดลองฟรี (ตั้งต้น 30 วัน) และบัญชีพร้อมเพย์ที่รับเงินได้ที่หน้า **ค่าสมาชิกช่าง** ช่างโอนผ่าน QR แล้วแนบสลิป ถ้าตั้ง `SLIP2GO_API_SECRET` ไว้ ระบบตรวจสลิปกับธนาคาร (บัญชีผู้รับ ยอดตรง โอนไม่เกิน 2 วัน ไม่เคยใช้) แล้วต่ออายุทันที ถ้ายังไม่ได้ตั้ง สลิปรอ Admin ตรวจ ระบบเตือนช่างเมื่อสมาชิกเหลือ 3 วันและเมื่อหมดอายุ และ Admin แจกวันใช้งานฟรีเพิ่มให้ช่างรายคนได้
- **เรื่องที่ถูกแจ้ง:** ปัญหาการชำระเงินและปัญหาหลังงานเสร็จ (ภายใน 14 วัน) รวมอยู่ที่หน้า **เรื่องที่ถูกแจ้ง** ของ Admin
- **ลบบัญชี:** ผู้ใช้ลบบัญชีเองได้ที่หน้าบัญชี ยืนยันด้วยรหัสผ่าน (หรือพิมพ์ “ลบบัญชี” สำหรับบัญชี Google) งานที่ยังไม่เริ่มถูกยกเลิกและแจ้งอีกฝ่าย ข้อเสนอที่ค้างของช่างถูกถอน งานที่กำลังทำ รอชำระเงิน หรือมีปัญหาค้างต้องปิดก่อน ชื่อ อีเมล เบอร์ รูป ที่อยู่ เอกสาร และอุปกรณ์รับแจ้งเตือนถูกลบ ประวัติงานและใบเสร็จเก็บไว้ในชื่อ “บัญชีที่ลบแล้ว” อีเมลเดิมสมัครใหม่ได้ บัญชี Admin ลบตัวเองไม่ได้
- **บัญชีและรหัสผ่าน:** กด “ลืมรหัสผ่าน?” ที่หน้าเข้าสู่ระบบ ระบบส่งลิงก์ทางอีเมล (ใช้ได้ครั้งเดียว ภายใน 30 นาที) ถ้าไม่ได้รับอีเมล Admin สร้างลิงก์ (ใช้ได้ 24 ชั่วโมง) ที่หน้า **ตรวจสอบช่าง** แล้วส่งให้ผู้ใช้หลังยืนยันตัวตนทางโทรศัพท์ เปลี่ยนรหัสผ่านได้ที่หน้าโปรไฟล์ เมื่อรีเซ็ตหรือเปลี่ยนรหัสผ่าน อุปกรณ์อื่นที่เข้าสู่ระบบไว้จะถูกออกจากระบบ
- **เข้าสู่ระบบด้วย Google:** เซิร์ฟเวอร์ตรวจลายเซ็นของโทเคนจาก Google ว่าออกให้แอปของเราจริงและยังไม่หมดอายุ ถ้าอีเมลที่ Google ยืนยันแล้วตรงกับบัญชีเดิม ระบบจะเชื่อมเข้าบัญชีนั้น ถ้ายังไม่มีบัญชีจะให้เลือกบทบาทก่อน (ช่างต้องกรอกเบอร์โทรและพื้นที่ และรอ Admin อนุมัติเหมือนเดิม) บัญชี Admin เข้าได้ด้วยรหัสผ่านเท่านั้น บัญชีที่สมัครด้วย Google ตั้งรหัสผ่านเพิ่มได้ที่หน้าโปรไฟล์
- **แจ้งเตือนในเว็บ (กระดิ่ง):** ทุกเหตุการณ์ของงานและบัญชีแสดงที่ไอคอนกระดิ่งพร้อมจำนวนที่ยังไม่อ่าน กดแล้วไปยังงานหรือหน้านั้นทันที
- **แจ้งเตือนบนมือถือ (Push):** เปิดได้ที่หน้าโปรไฟล์ทีละอุปกรณ์ ใช้ได้กับ Chrome, Edge, Firefox และ Safari บน iPhone ต้อง “เพิ่มไปยังหน้าจอโฮม” ก่อน (iOS 16.4 ขึ้นไป) เปิดผ่าน Messenger/LINE จะรับไม่ได้ ระบบสร้างกุญแจ VAPID ให้เองโดยไม่ต้องตั้งค่า และเมื่อออกจากระบบ อุปกรณ์นั้นจะหยุดรับการแจ้งเตือน
- **ไม่ส่งอีเมลแจ้งเตือนงาน:** แจ้งเตือนงานใช้กระดิ่งและ Push เท่านั้น อีเมลใช้เฉพาะลืมรหัสผ่าน
- **ที่อยู่ที่บันทึกไว้:** เก็บในบัญชีผู้ใช้ (สูงสุด 20 รายการ) จึงเห็นเหมือนกันทุกเครื่อง ที่อยู่ที่เคยบันทึกไว้ในเบราว์เซอร์ระบบย้ายเข้าบัญชีให้อัตโนมัติ

## 7. เทคโนโลยี

- Frontend: React 18, TypeScript, Vite, ติดตั้งเป็น PWA ได้
- แผนที่: Leaflet และ OpenStreetMap (ค้นที่อยู่ด้วย Google Places ได้ถ้าตั้ง `VITE_GOOGLE_MAPS_API_KEY`)
- Backend: ASP.NET Core 8 Web API
- Database: MongoDB Atlas (เก็บรูปงาน เอกสาร และสลิปในฐานข้อมูลด้วย)
- Authentication: JWT, รหัสผ่านแบบ hash ของ ASP.NET Identity, Google sign-in และจำกัดจำนวนครั้งที่ลองเข้าสู่ระบบ
- บริการภายนอก: Brevo (อีเมลรีเซ็ตรหัสผ่าน), Web Push (VAPID), Slip2Go (ตรวจสลิปพร้อมเพย์)
- Deployment: Render สำหรับ Frontend (static site) และ Backend (Docker) และ GitHub Actions สำหรับ CI และปลุกเซิร์ฟเวอร์ส่งแจ้งเตือนทุก 30 นาที

## 8. API ของตลาดงาน

- `POST /api/bookings` — ลูกค้าสร้างคำขอโดยยังไม่ระบุช่าง
- `GET /api/technician-jobs?latitude=...&longitude=...&radiusKm=25` — ช่างค้นหางานตามตำแหน่งและระยะค้นหา
- `POST /api/bookings/{id}/applications` — ช่างส่งความสนใจรับงานและข้อเสนอราคา
- `POST /api/bookings/{id}/confirm-technician` — ลูกค้ายืนยันช่างจากผู้ที่ส่งความสนใจ
- `GET /api/bookings` — ดูรายการจองตามสิทธิ์ของบัญชี
- `PATCH /api/bookings/{id}/status` — เปลี่ยนสถานะงานตามขั้นตอนและสิทธิ์
- `POST /api/bookings/{id}/location` — ช่างอัปเดตตำแหน่งระหว่างเดินทาง
- `POST /api/bookings/{id}/reviews` — ลูกค้าให้คะแนนช่างหลังงานเสร็จ
- `GET/PATCH /api/technicians/me` — ช่างดูและแก้ไขโปรไฟล์บริการ ราคา พื้นที่ เบอร์โทร และดูสถานะการตรวจสอบ
- `GET /api/admin/technicians?status=Pending` — Admin ดูคิวช่างที่รอตรวจสอบ
- `PATCH /api/technicians/{id}/verification` — Admin อนุมัติ (`verified: true`) หรือไม่ผ่าน/ระงับ (`verified: false` พร้อม `note`)
- `POST /api/auth/forgot-password`, `POST /api/auth/reset-password`, `POST /api/auth/change-password` — ลืม/ตั้ง/เปลี่ยนรหัสผ่าน
- `POST /api/admin/password-reset-links` — Admin สร้างลิงก์ตั้งรหัสผ่านใหม่ให้ผู้ใช้
- `POST /api/auth/external` — เข้าสู่ระบบ/สมัครด้วย Google (ส่ง ID token จาก Google)
- `GET/POST /api/me/addresses`, `DELETE /api/me/addresses/{id}` — ที่อยู่ที่บันทึกไว้ของบัญชี
- `GET/POST /api/air-conditioners`, `DELETE /api/air-conditioners/{id}` — ลูกค้าจัดการเครื่องใน Aircon Passport (`POST /api/bookings` รับ `airConditionerId` ได้แบบไม่บังคับ)

ส่วนที่เพิ่มเข้ามาภายหลัง:

- `POST /api/price-estimate`, `GET /api/price-guide` — ราคากลางของงานสำหรับฟอร์มลูกค้า และราคาที่ช่างส่วนใหญ่คิดสำหรับหน้าตั้งราคาของช่าง
- `POST /api/technicians/me/submit` — ช่างส่งข้อมูลให้ Admin ตรวจ (ตอบกลับว่ายังขาดอะไร) และ `GET/POST /api/technicians/me/documents`, `DELETE /api/technicians/me/documents/{id}` สำหรับรูปบัตรประชาชน
- `POST /api/bookings/{id}/reopen` — เปิดรับช่างใหม่หลังข้อเสนอหมดอายุ
- `POST /api/bookings/{id}/reschedule` — เปลี่ยนวันนัด (ก่อนช่างออกเดินทาง)
- `POST /api/bookings/{id}/changes`, `POST /api/bookings/{id}/changes/{changeId}/answer`, `DELETE /api/bookings/{id}/changes/{changeId}` — ช่างขอปรับราคาหน้างาน ลูกค้าตอบ และช่างถอนคำขอ
- `POST /api/bookings/{id}/progress`, `POST /api/bookings/{id}/photos`, `GET /api/bookings/{id}/photos` — ติ๊กห้องที่เสร็จ และรูปก่อน/หลังล้าง
- `POST /api/bookings/{id}/complete` — ช่างกด “งานเสร็จและได้รับเงินแล้ว”, `PATCH /api/bookings/{id}/payment-confirmation` — ยืนยันการจ่ายเงิน
- `POST /api/bookings/{id}/payment-issue`, `POST /api/bookings/{id}/report-problem`, `GET /api/admin/issues`, `POST /api/admin/issues/{id}/resolve` — แจ้งปัญหาและการตัดสินของ Admin
- `GET/POST /api/bookings/{id}/receipt` — ดูและออกใบเสร็จ
- `GET /api/technicians/me/membership`, `POST /api/technicians/me/membership/payments` — สถานะสมาชิกและส่งสลิป, `GET /api/admin/membership`, `PUT /api/admin/membership/settings`, `POST /api/admin/membership/payments/{id}/review`, `POST /api/admin/technicians/{id}/membership/grant` — ฝั่ง Admin
- `GET/POST /api/auth/delete-account` — ดูผลก่อนลบ และลบบัญชี
- `GET /api/notifications`, `POST /api/notifications/read`, `POST /api/push/subscriptions` — กระดิ่งและ Push
- `POST /api/cron/reminders` — ให้ GitHub Actions ปลุกเซิร์ฟเวอร์ส่งแจ้งเตือน (ต้องมี header `X-Cron-Key` และใช้ได้เมื่อตั้ง `CRON_KEY` เท่านั้น)

## 9. สิ่งที่ควรทราบก่อนใช้งานจริง

- การค้นหางานใกล้ตัวต้องอนุญาต GPS บนอุปกรณ์ และต้องมีโปรไฟล์ช่างเชื่อมกับบัญชีผู้ใช้
- ราคาที่เห็นในฟอร์มขอช่างเป็นราคากลางจากใบราคาของช่างในระบบ (หรือราคาอ้างอิงถ้ามีช่างไม่ถึง 3 คน) ราคาจริงคือราคาที่ช่างแต่ละคนเสนอ ซึ่งล็อกเมื่อลูกค้ากดยืนยัน
- ตั้ง `CRON_KEY` บน API และ secret `AIRCLEAN_API_URL`, `AIRCLEAN_CRON_KEY` บน GitHub ไม่อย่างนั้นแจ้งเตือนตามเวลาจะออกเฉพาะตอนเซิร์ฟเวอร์ตื่นอยู่
- ตั้ง `SLIP2GO_API_SECRET` เพื่อตรวจสลิปค่าสมาชิกอัตโนมัติ และตั้งบัญชีพร้อมเพย์ในหน้า **ค่าสมาชิกช่าง** ก่อนให้ช่างจ่ายเงิน
- การคำนวณระยะทางเป็นเส้นตรง ยังไม่ใช่ระบบค้นหาเส้นทางตามถนนหรือ ETA แบบเรียลไทม์
- เปิดใช้ Google: สร้าง OAuth Client ID ประเภท Web application ใน Google Cloud Console ใส่ Authorized JavaScript origins เป็นที่อยู่เว็บ แล้วตั้ง `GOOGLE_CLIENT_ID` (API) และ `VITE_GOOGLE_CLIENT_ID` (Static Site) เป็นค่าเดียวกัน
- หน้านโยบายความเป็นส่วนตัว `/privacy.html` และข้อกำหนดการใช้งาน `/terms.html` มีลิงก์จากหน้าแรกและหน้าเข้าสู่ระบบ ใช้กรอกใน Google Auth Platform → Branding อีเมลติดต่อบนหน้านี้ตั้งด้วย `VITE_CONTACT_EMAIL` บน Static Site เนื้อหาเป็นร่างเริ่มต้น ควรตรวจทานก่อนเปิดใช้จริง
- ตั้งค่าการส่งอีเมล: Render แพลนฟรีบล็อกการเชื่อมต่อ SMTP จึงใช้ `BREVO_API_KEY` (ส่งผ่าน HTTPS) คู่กับ `SMTP_FROM` แล้วตรวจด้วยปุ่ม **ส่งอีเมลทดสอบ** ในหน้าตรวจสอบช่าง ค่า `SMTP_HOST` และอื่นๆ ใช้เฉพาะเมื่อไม่ได้ตั้ง `BREVO_API_KEY`
- หลัง deploy ให้ตรวจคิว **ตรวจสอบช่าง** เพราะโปรไฟล์ช่างเดิมที่ยังไม่เคยยืนยันจะกลายเป็น “รอตรวจสอบ”
- บัญชีผู้ดูแลอาคาร (Manager) ยังเลือกสมัครได้เองตอนลงทะเบียน
- ก่อนเปิดให้บริการจริง ควรทดสอบเส้นทางครบทั้งลูกค้าและช่าง ตรวจสอบสิทธิ์/ความเป็นส่วนตัว และยืนยันสถานะการ Deploy บน Render อีกครั้ง

## 10. สรุป

AirClean ทำงานตามแนวคิด **ลูกค้าส่งคำขอ → ช่างใกล้เคียงส่งความสนใจและเสนอราคา → ลูกค้าเลือกยืนยันช่าง → ช่างเดินทางและให้บริการ** จุดสำคัญคือความสะดวกของลูกค้า ความชัดเจนของข้อเสนอสำหรับช่าง และการไม่เผยตำแหน่งบ้านที่แม่นยำก่อนลูกค้ายืนยันช่าง ส่วนประวัติการล้างและระบบอาคารรายห้องช่วยให้ลูกค้ากลับมาใช้ซ้ำตามรอบ ราคาที่คิดจากใบราคาของช่างพร้อมราคากลางทำให้ลูกค้าตัดสินใจได้โดยไม่ต้องรู้ราคาตลาด และค่าสมาชิกรายเดือนที่ตรวจสลิปอัตโนมัติทำให้ AirClean มีรายได้โดยไม่ต้องถือเงินค่าล้างแอร์
